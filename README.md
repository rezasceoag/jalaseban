# جلسه‌بان

وب‌اپ داخلی و فارسی برای تبدیل فایل صوتی جلسه به متن گوینده‌بندی‌شده، خلاصه، تصمیم‌ها و تسک‌ها.

## راه‌اندازی

1. در Supabase یک پروژه بسازید و محتوای `supabase/schema.sql` را در SQL Editor اجرا کنید.
2. پروژه را در Vercel وارد کنید.
3. متغیرهای موجود در `.env.example` را در Project Settings → Environment Variables قرار دهید.
4. Deploy را اجرا کنید.

بدون متغیرهای محیطی، وب‌اپ با داده نمونه اجرا می‌شود تا رابط کاربری قابل بررسی باشد.

## اجرای محلی

```bash
npm install
npm run dev
```

## مسیر پردازش

- فایل از مرورگر مستقیماً به فضای خصوصی Supabase Storage می‌رود.
- Vercel Function فایل را با `gpt-4o-transcribe-diarize` به متن و گویندگان تبدیل می‌کند.
- مدل تعریف‌شده در `OPENAI_TEXT_MODEL` خلاصه، تصمیم‌ها، تسک‌ها و موضوعات باز را می‌سازد.
- تمام نتیجه در جدول `meetings` ذخیره و در همان وب‌اپ نمایش داده می‌شود.

## محدودیت نسخه اولیه

- حداکثر اندازه فایل ۲۴ مگابایت است.
- پردازش هم‌زمان انجام می‌شود و تابع Vercel حداکثر ۳۰۰ ثانیه فرصت دارد.
- `APP_PASSWORD` یک رمز مشترک داخلی است و برای نسخه عمومی یا چندشرکتی مناسب نیست.
